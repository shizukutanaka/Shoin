# Shoin FAQ

**Q. NotebookLMと何が違う?**
A. 文書が外部に出ません。NotebookLMはGoogleクラウドで処理しますが、Shoinは取込・検索・生成の全てがあなたのPC内で完結します。加えて、回答中の引用を機械的に検証し、存在しないソースの引用(citation hallucination)を検出・表示します。

**Q. 必要なスペックは?**
A. 8GB RAMのPCで動きます(Qwen3-4B量子化想定)。GPU不要。16GB以上あればQwen3-8Bでより高品質に。

**Q. インターネット接続は必要?**
A. モデルの初回ダウンロードとURL取込時のみ。それ以外は完全オフラインで動作します。

**Q. どのLLMが使える?**
A. OpenAI互換APIを話せるローカルランタイム(Ollama / llama.cpp / LM Studio)上の任意モデル。推奨はQwen3-4B/8B、Gemma 3 4B、Phi-4-mini。

**Q. 埋め込みモデルは必須?**
A. 任意です。未設定でもBM25全文検索で動作します。`nomic-embed-text`(英語中心)や`ruri-v3`(日本語特化)を入れると検索精度が上がります。

**Q. データはどこに保存される?**
A. `~/.local/share/shoin/` 配下のSQLiteファイル1つ。バックアップはこのファイルをコピーするだけです。

**Q. 対応している文書形式は?**
A. PDF / Markdown / プレーンテキスト / HTML / URL。YouTube字幕等の追加形式は将来的な検討課題です(具体的な予定はありません)。

**Q. 音声概要(ポッドキャスト)は?**
A. 現在は非対応です。TTS依存(VOICEVOX / Piperなど)を追加すると「依存最小」の設計原則と緊張するため、優先度は低く設定しています。

**Q. 引用はどう機能する?**
A. 回答中の `[S1]` をクリックすると、根拠となった原文チャンクがハイライト表示されます。実在しないソース番号が引用された場合は赤くフラグされます。

**Q. 日本語の精度は?**
A. UIと設計は日本語一次です。回答品質はモデル依存ですが、推奨のQwen3系はCJK性能が高く、日本語埋め込みにはruri-v3を選べます。

**Q. 商用利用は?**
A. MITライセンスです。利用・改変・再配布・商用利用すべて可能です。

**Q. チームで共有できる?**
A. 設計上シングルユーザーです(127.0.0.1バインド固定)。チーム用途にはSurfSense等をご検討ください。
